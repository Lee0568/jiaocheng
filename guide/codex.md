# 如何在Codex中使用Uns-Link key

OpenCode 是一个开源代理，帮助您使用任意 AI 模型编写和运行代码。它提供终端界面、桌面应用及 IDE 扩展。

官网：[OpenCode](https://opencode.ai/zh)

## 计费单位

- **额度**: 美元（$）
- **Token**: 输入/输出 token 分开计费

## 计费规则

### 按量计费

根据实际使用的 token 数量计费：

```
费用 = 输入token数 × 输入价格 + 输出token数 × 输出价格
```

### 倍率计费

可设置倍率调整价格：

```
实际价格 = 基础价格 × 倍率
```

## 查看使用量

### 个人使用统计

1. 进入 **仪表盘**
2. 查看今日/本月使用量
3. 查看各模型使用分布

### 管理员统计

1. 进入 **控制台** -> **使用统计**
2. 查看全局使用数据
3. 导出统计报表

## 额度管理

### 用户额度

| 配置项   | 说明             |
| -------- | ---------------- |
| 总额度   | 用户可用的总金额 |
| 已用额度 | 已消耗的金额     |
| 剩余额度 | 剩余可用金额     |

### 令牌额度

令牌可以设置独立额度：

```bash
# 设置令牌额度
curl -X PUT http://localhost:3000/api/token/1 \
  -H "Authorization: Bearer admin-token" \
  -d '{"quota": 1000}'
```

### 额度告警

可配置额度使用告警：

- 80% 使用时告警
- 95% 使用时告警
- 额度耗尽时告警

## 账单明细

### 查看账单

进入 **控制台** -> **账单明细** 查看详细记录：

| 字段      | 说明          |
| --------- | ------------- |
| 时间      | 请求时间      |
| 模型      | 使用的模型    |
| 输入token | 输入 token 数 |
| 输出token | 输出 token 数 |
| 费用      | 本次费用      |
| 渠道      | 使用的渠道    |

### 导出账单

支持导出为 CSV 格式：

```bash
# 通过 API 导出
curl -X GET "http://localhost:3000/api/log/export?start=2024-01-01&end=2024-01-31" \
  -H "Authorization: Bearer admin-token" \
  -o bills.csv
```

## 免费额度

### 新用户免费额度

可配置新用户注册赠送额度：

```bash
# 环境变量配置
NEW_USER_QUOTA=1000000  # 100万 token
```

### 邀请奖励

邀请新用户可获得额度奖励。

## 成本控制

### 设置额度上限

```bash
# 用户额度上限
MAX_USER_QUOTA=10000000

# 令牌额度上限
MAX_TOKEN_QUOTA=5000000
```

### 限流控制

通过限流控制成本：

```json
{
  "rate_limit": {
    "rpm": 60,
    "tpm": 100000
  }
}
```
