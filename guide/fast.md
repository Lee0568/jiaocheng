# 🚀 API 快速开始指南

> **欢迎开启您的 Uns-Link 之旅**
> 只需简单 3 步，即可完成接入并开始调用强大的 AI 模型服务。

---

## 🔑 Step 1. 获取 API 密钥

为了保障接口调用的安全性，您需要先获取专属的访问令牌。

1. **登录控制台**：使用您的账号登录 Uns-Link 控制台。
2. **生成密钥**：导航至左侧菜单的 `【API密钥】` 页面。
3. **创建密钥**：点击页面左上角的 **「创建API密钥」** 按钮，系统将自动生成您的专属 API密钥。

💡 **分组选择建议**

* **满血分组（1.2倍）**：均为纯血产品，提供最高的稳定性与可用性保障。且保证为官方api。
* **特惠分组 (🌟 推荐-0.5倍)**：系统将智能路由，自动为您匹配当前最具性价比的节点通道，但不保证稳定。
* **默认分组（0.8倍）**：保证可用性、稳定性的同时，价格相对低廉。

---

## 🌐 Step 2. 核心接口配置 (Base URL)

根据您的业务需求，选择对应的通用 API 端点地址。

### 💬 大语言模型 (LLM) 通用端点

适用于文本对话、代码生成、逻辑推理等场景。
`https://unslink.cc/v1/`

### 🎨 图像生成模型通用端点

适用于文生图、图生图等 AIGC 视觉场景。
`https://unslink.cc/v1/`

> ⚠️ **特殊模型说明**
> 极少数特定模型可能使用独立的 API 端点。若调用失败，请前往 🛒 **[模型广场](https://unslink.cc/pricing)** ，点击对应模型查看其专属的接入地址。

---

## 🧠 Step 3. 选择与测试模型

我们提供丰富的模型矩阵供您调用，完整列表请查阅 🛒 **[模型广场](https://unslink.cc/pricing)**。

### 🛠️ 接入配置示例

在您的代码或请求工具中，请参考以下 JSON 格式进行鉴权与传参：

```json
{
    "base_url":"https://unslink.cc/v1",
    "api_key": "your_token_here",
    "model": "gpt-5.4"
}
```

在该模块中，您可以直接选择分组及模型，对各个模型的响应速度和生成质量进行直观的在线测试。
